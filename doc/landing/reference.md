# Référence des fichiers

[Sommaire](README.md)

Chaque fiche recense les types, constructeurs, méthodes, constantes, champs, variables locales et paramètres déclarés dans le fichier. Les signatures fournissent les types et valeurs initiales ; les dépendances indiquent les points de raccordement. Les variables de boucle sont recensées séparément des états persistants.
