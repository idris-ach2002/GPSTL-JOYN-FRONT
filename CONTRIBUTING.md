# Contribuer à JOYN

La procédure de contribution est volontairement centralisée pour éviter plusieurs versions des mêmes règles.

1. Lire le [README](README.md), en particulier **Règles de travail** et l'exemple de workflow complet.
2. Utiliser les scripts de `scripts/dev/` pour créer, synchroniser, valider et pousser une branche.
3. Consulter [docs/workflow.md](docs/workflow.md) pour le détail Git / CI/CD.
4. Respecter [docs/architecture.md](docs/architecture.md) pour les frontières Web / Mobile.

`main` est protégée : toute modification passe par une Pull Request et les checks CI requis.
